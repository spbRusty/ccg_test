# Стабильность — карточная дуэль

Ветка `rewrite/excalibur` содержит отдельный прототип дуэли для двух лагерей в постапокалипсисе. Основная механика — одна шкала **Стабильности**: это одновременно здоровье и цена розыгрыша карт.

## Правила прототипа

- У каждого игрока 15 Стабильности (или 20 в настройке), максимум — 60. Нельзя оплатить карту, если после оплаты останется 0.
- В колоде 30 карт, стартовая рука — 5, предел руки — 6. В начале следующего раунда добирается одна карта.
- На поле по 6 слотов. Разыгранные карты остаются на поле; карты с эффектом «при розыгрыше» срабатывают один раз, эффекты «в конце хода» повторяются.
- Игроки выбирают карты закрыто, стоимость списывается сразу. До блокировки выбора карту можно отменить с возвратом стоимости.
- Клапан позволяет за 2 Стабильности взять карту, если в руке есть место и после оплаты останется минимум 1.
- Карты нового раунда нельзя снять эффектом удаления в том же раунде. Игрок может убрать собственную карту до блокировки выбора.
- Можно включить ограничение в две карты за раунд. По умолчанию отдельного лимита нет, кроме доступной Стабильности, руки и свободных слотов.
- Победа — Стабильность противника достигает 0. Если обе шкалы одновременно равны 0, фиксируется ничья.

## Запуск

```bash
npm install
npm run dev
```

Проверки, сборка и симуляция:

```bash
npm run check
npm test
npm run build
npm run stability:simulate -- 1000 1
```

Симулятор сохраняет CSV и Markdown-отчёт в `reports/stability-simulation.*`. Он запускает одинаковый эвристический ИИ за обе стороны и предназначен для поиска перекоса первого хода и затяжных матчей, а не для автоматической балансировки карт.

## Статус и ограничения

- Ветка не опубликована в `main`; GitHub Pages основной ветки не изменён.
- Игровые правила вынесены в отдельный модуль, тесты проверяют ключевые условия.
- Excalibur рисует фон арены, рамки шести слотов и декоративные частицы. Карты, шкалы и интерактивные кнопки пока HTML/CSS; анимации игровых действий ещё не готовы.
- Противник — локальный эвристический ИИ, не сетевой мультиплеер.
- Баланс 30 карт — черновой. Симуляция зависит от простой эвристики и не заменяет тесты с реальными игроками.
