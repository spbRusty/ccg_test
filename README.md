# Временной разлом — прототип ККИ

Браузерный прототип карточной игры на обычных HTML, CSS и JavaScript. Без сборки, зависимостей и мультиплеера.

## Запуск

Откройте `index.html` в браузере или запустите локальный сервер из каталога проекта:

```bash
python3 -m http.server 8080
```

Затем откройте http://localhost:8080.

## Правила прототипа

- У каждого игрока 60 секунд. Это ресурс, а не реальный таймер обратного отсчёта.
- Стоимость разыгранной карты вычитается из времени её владельца.
- За ход можно разыграть одну карту или пропустить ход.
- Карта занимает один из шести слотов на поле владельца. Если все слоты заняты, новая карта заменяет самую старую.
- В конце хода игрок добирает карту до пяти в руке; максимум в руке — семь.
- Когда время одного игрока достигает нуля, он проигрывает.
- После хода игрока действует простой ИИ.

## Эффекты карт

- **Импульс / Резерв времени:** восстановление времени.
- **Вор времени:** перенос времени от противника себе.
- **Перестановка:** обмен текущими запасами времени.
- **Ускоритель:** скидка на следующую карту.
- **Замедлитель:** следующая карта противника стоит дороже.
- **Эхо:** повтор предыдущего эффекта карты.
- **Срыв:** убирает последнюю карту противника с поля и восстанавливает время.
- **Отложенный импульс:** переносит время в начале следующего хода противника.
- **Критический момент:** сильнее действует, когда у противника меньше 20 секунд.
- **Доля секунды:** переносит 10% оставшегося времени противника.

Перетаскивание работает мышью. На сенсорных экранах можно выбрать карту касанием, затем нажать на слот своего поля.

## Ограничения текущей версии

Это прототип для проверки основного игрового цикла. Баланс карт, графика, анимации, звук, обучение и полноценные автоматические тесты пока не добавлены.
