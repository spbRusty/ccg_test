# Стабильность — короткая карточная дуэль

Постапокалиптическая карточная игра с антропоморфными овощами, одновременным выбором ходов и одной шкалой **Стабильности**. Поддерживаются компьютер и мобильные экраны; противник — локальный ИИ. Сетевой PvP пока не подключён.

## Базовые правила

- В коллекции **120 уникальных карт**.
- В колоде **12 разных карт**, каждая только в одном экземпляре.
- В начале партии игрок получает **4 карты**; в конце каждого хода добирает из колоды до **4 карт**.
- На поле у каждого игрока **4 слота**. За ход можно выставить карты в любые из четырёх слотов; один слот — одна карта.
- Начальная Стабильность — **30**, предел восстановления — **60**.
- Стоимость карты может быть положительной или отрицательной: положительная уменьшает Стабильность, отрицательная восстанавливает её.
- Оплата картой не может снизить свою Стабильность ниже **1**. При Стабильности 1 карты, которые должны её уменьшить, становятся бесплатными.
- Карты выкладываются закрытыми для соперника. После фиксации обоих ходов карты раскрываются по слотам **1 → 2 → 3 → 4**.
- Первым в каждом слоте срабатывает игрок с меньшей Стабильностью на момент начала раскрытия. При равенстве порядок выбирается случайно. Затем срабатывает карта второго игрока в том же слоте.
- В конце хода после эффектов каждая занятая ячейка уменьшает Стабильность соперника на 1; каждая свободная ячейка восстанавливает владельцу 1 Стабильность.
- Карты не имеют атаки и здоровья. Победа наступает, когда Стабильность соперника достигает 0; одновременное обнуление — ничья. После 7-го раунда побеждает сторона с большей оставшейся Стабильностью.

## Эффекты

- **При раскрытии** — разовый эффект в текущем раунде.
- **В конце каждого раунда** — повторяющийся эффект карты на поле.
- Существуют прямое уменьшение/восстановление Стабильности, перенос Стабильности, добор, усиление следующего эффекта, отложенный эффект, щит, запрет лечения, удаление и возврат карт, а также условия по размеру поля, руке и выбранным картам.
- Удалять можно только карты, уже стоявшие на поле до начала текущего раунда.

## Баланс и проверки

В наборе 120 именованных карт, распределённых по семи отрядам: рейдеры, сборщики, медики, технари, дозор, караван и легенды. Прямые эффекты имеют цену близкую к немедленному эффекту; повторяющиеся эффекты стоят дороже, поскольку могут работать несколько раундов. Состав колоды и вероятности эффектов требуют дальнейшего тестирования с игроками.

Запуск и проверки:

```bash
npm install
npm run dev
npm run check
npm test
npm run build
```

## Технологии

TypeScript, Vite. Интерфейс игры адаптивный, без прокрутки страницы во время битвы. Арты используют AVIF с JPEG-fallback.
