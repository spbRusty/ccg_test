# Временной разлом — Excalibur.js rewrite

Новая ветка прототипа карточной игры на Excalibur.js. Предыдущая реализация сохранена в истории Git и в исходных игровых модулях.

## Текущий вертикальный срез

- Excalibur.js рендерит игровое поле и интерактивные игровые объекты.
- Тактическое поле состоит из трёх линий; на каждой стороне может стоять по одному существу на линию.
- У игрока 25 здоровья, мана растёт на 1 в начале каждого хода до 10.
- Карты разыгрываются за ману, а существа атакуют по своей линии в конце хода.
- Противник управляется простым ИИ.
- Карты переиспользуют существующие названия и категории эффектов, но стоимость и характеристики пересчитаны для нового прототипа.
- Есть мобильное масштабирование через Excalibur FitScreen.

## Запуск

```bash
npm install
npm run dev
```
